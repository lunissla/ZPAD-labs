# Lab 7 — OpenCV + Face Detection + Multithreading (C++)


## Опис

Програма захоплює відео з камери, відображає його та застосовує різні ефекти залежно від натиснутих клавіш.
У цій лабораторній роботі додано:

- детекцію облич за допомогою нейромережі (OpenCV DNN, Caffe ResNet-10 SSD),

- фоновий потік, який виконує інференс без блокування FPS,

- плавну роботу відео, навіть коли детекція займає багато часу,

- перемикання режимів обробки зображення (фільтри 1–6),

- вмикання/вимикання детекції облич клавішею F.


## Вимоги:


- ОС: Ubuntu 20.04+ (або інший Linux  що підтримує камеру)

- Компілятор: GCC 11+ або Clang

- OpenCV: 4.x
