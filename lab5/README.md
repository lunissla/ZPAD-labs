# Лабораторна робота 5 – Аналіз часових рядів VCI/TCI/VHI у Streamlit

## Мета

- Створити інтерактивний веб-додаток на основі Streamlit
- Виконати аналіз часових рядів VCI, TCI, VHI
- Реалізувати фільтрацію даних за роками, тижнями та регіонами
- Побудувати графіки для аналізу та порівняння областей
- Додати можливість сортування даних

## Опис

У даній лабораторній роботі реалізовано веб-додаток для аналізу індексів вегетаційного стану (VCI, TCI, VHI) на основі даних NOAA по регіонах України. Користувач може вибирати тип індексу, область, а також обмежувати дані за часовими інтервалами (тижні та роки). Додатково реалізовано сортування даних та візуалізацію результатів у вигляді таблиць і графіків.

## Інструкція із запуску

Клонувати репозиторій за допомогою команди:

```git clone <URL_репозиторію>```

та перейти до теки лабораторної роботи:

```cd <назва_теки>```

Створити та активувати віртуальне середовище (рекомендовано):

```python -m venv venv```

Для Windows:
```venv\Scripts\activate```

Для Linux / macOS:
```source venv/bin/activate```

Встановити необхідні залежності:

```pip install -r requirements.txt```

Запустити Streamlit командою:

```streamlit run app.py```

Після запуску необхідно відкрити файл harmonic.ipynb і виконати всі комірки послідовно.

## Інструкція користувача

Додаток містить інтерактивні елементи керування для аналізу даних.

Фільтри:

- Index (dropdown) — вибір індексу VCI, TCI або VHI
- Region (dropdown) — вибір області
- Weeks (slider) — вибір діапазону тижнів
- Years (slider) — вибір діапазону років

Додаткові елементи:

- Reset button — скидання всіх фільтрів до початкових значень
- Sort ascending checkbox — сортування за зростанням
- Sort descending checkbox — сортування за спаданням

Якщо увімкнено обидва варіанти сортування одночасно, сортування не застосовується і виводиться попередження.
