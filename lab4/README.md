# Лабораторна робота 4 – Гармоніка з шумом та фільтром

## Мета

- Створити інтерактивний графік гармоніки виду y(t) = A*sin(ωt + φ)  
- Додати шум і відобразити його  
- Фільтрувати зашумлену гармоніку  
- Додати інтерактивні елементи: слайдери, чекбокси, кнопку Reset  

## Опис

У даній лабораторній роботі реалізовано програму для побудови гармонічного сигналу з можливістю додавання шуму та подальшої фільтрації. Користувач може змінювати параметри сигналу та шуму в реальному часі за допомогою інтерактивного інтерфейсу. Також відображається результат фільтрації, що дозволяє порівняти чистий, зашумлений та відфільтрований сигнали.

## Інструкція користувача

Програма містить інтерактивні елементи керування, які дозволяють змінювати параметри сигналу та одразу бачити результат на графіку.

Слайдери гармоніки:
- Amplitude — задає амплітуду сигналу
- Frequency — задає частоту сигналу
- Phase — задає фазовий зсув

Слайдери шуму:
- Noise Mean — середнє значення шуму
- Noise Var — дисперсія шуму (інтенсивність)

Чекбокс:
- Show Noise — вмикає або вимикає відображення шуму на сигналі

Параметри фільтра:
- Cutoff — частота зрізу фільтра
- Order — порядок фільтра

Кнопка:
- Reset — повертає всі параметри до початкових значень

## Особливості роботи

- При зміні параметрів гармоніки шум залишається незмінним  
- При зміні параметрів шуму генерується новий шум  
- Якщо шум вимкнений, відображається чиста гармоніка  
- Фільтр автоматично застосовується до зашумленого сигналу  
- Всі зміни параметрів миттєво відображаються на графіку
